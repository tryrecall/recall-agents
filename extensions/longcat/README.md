# SteelEngine LongCat Provider

Official SteelEngine provider plugin for LongCat-2.0 through LongCat's hosted
OpenAI-compatible API.

Install from SteelEngine:

```bash
steelengine plugins install @steelengine/longcat-provider
steelengine gateway restart
```

Configure `LONGCAT_API_KEY`, then select `longcat/LongCat-2.0`.
