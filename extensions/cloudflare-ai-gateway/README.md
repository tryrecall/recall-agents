# SteelEngine Cloudflare AI Gateway Provider

Official SteelEngine provider plugin for Cloudflare AI Gateway.

Install from SteelEngine:

```bash
steelengine plugins install @steelengine/cloudflare-ai-gateway-provider
steelengine gateway restart
```

See <https://docs.steelengine.ai/providers/cloudflare-ai-gateway> for setup and configuration.
