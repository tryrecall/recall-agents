# Tencent Cloud SteelEngine provider

Official SteelEngine provider plugin for Tencent Cloud.

## Install

```sh
steelengine plugins install @steelengine/tencent-provider
```

## Docs

See `docs/providers/tencent.md` in the SteelEngine repository, or the published docs at `https://docs.steelengine.ai/providers/tencent`.
