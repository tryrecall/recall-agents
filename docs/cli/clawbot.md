# `steelengine clawbot`

Legacy alias namespace kept for backward compatibility. It registers the same QR command as the top-level CLI, so `steelengine clawbot qr` accepts every [`steelengine qr`](/cli/qr) flag.

## Migration

Prefer the modern top-level command:

- `steelengine clawbot qr` -> `steelengine qr`
