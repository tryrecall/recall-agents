# BytePlus plugin

Adds BytePlus, BytePlus Plan model provider support to SteelEngine.

## Distribution

- Package: `@steelengine/byteplus-provider`
- Install route: included in SteelEngine

## Surface

providers: `byteplus`, `byteplus-plan`; contracts: `videoGenerationProviders`
